# Users API

A user is a person with a required name and an optional surname (spelled `surename` in the API). Source: `internal/api/routes/user.go`.

| Method | URL | Auth | Purpose |
|---|---|---|---|
| POST | `/api/v1/users/newData` | — | Create a user |
| GET | `/api/v1/users/getData` | — | List users (paginated, name search) |
| GET | `/api/v1/users/info/:id` | — | Get one user |
| PUT | `/api/v1/users/update/:id` | — | Update a user |
| DELETE | `/api/v1/users/:id` | — | Delete a user |

## Types

```ts
// Response shapes (schemas/responsebody)
export interface User {
  id: string;              // UUID, generated by the server
  name: string;
  surename: string | null; // sent as null when not set, never omitted
}

// Request shapes (schemas/requestbody)
export interface CreateUserRequest {
  name: string;            // required, max 255 chars
  surename?: string | null; // optional, max 255 chars; omitted/null = stored as null
}

export interface UpdateUserRequest {
  name: string;            // required, max 255 chars
  surename?: string | null; // optional, max 255 chars; omitted/null = left unchanged
}

export interface ListUsersQuery {
  page?: number;           // min 1, default 1
  per_page?: number;       // min 1, max 100, default 20
  q?: string;              // max 255 chars; case-insensitive "contains" match on name
}
```

## POST `/api/v1/users/newData`

Create a user. Auth: none.

**Body** (`application/json`)

| Key | Type | Required | Rule | Go field (in 400 errors) |
|---|---|---|---|---|
| `name` | string | yes | max 255 characters | `Name` |
| `surename` | string \| null | no | max 255 characters | `Surename` |

**Request example**

```ts
const res = await fetch(`${BASE_URL}/users/newData`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name: "Somchai", surename: "Phommavong" }),
});
const json: ApiResponse<User> = await res.json();
```

**Success: 200** (returns the created user)

```json
{ "timestamp": "2026-01-02-15-04-05", "status": 1, "items": { "id": "3f1c2a9e-8b7d-4c6e-9a51-2d0f7b8e4c13", "name": "Somchai", "surename": "Phommavong" }, "error": null }
```

**Errors**

| HTTP | `error` message | When | UI action |
|---|---|---|---|
| 400 | `Field 'Name' \| Needs to pass 'required' validation` | `name` missing or `""` | highlight `name` |
| 400 | `Field 'Name' \| Needs to pass 'max' validation` | `name` > 255 chars | highlight `name` |
| 400 | `Field 'Surename' \| Needs to pass 'max' validation` | `surename` > 255 chars | highlight `surename` |
| 400 | `Unprocessable Entity` / JSON parse message | wrong content type / malformed JSON | generic error toast |
| 500 | database error text | unexpected server error | generic error toast |

## GET `/api/v1/users/getData`

List users sorted by name, one page at a time, optionally filtered by name. Auth: none.

**Query params**

| Key | Type | Required | Rule | Default | Go field (in 400 errors) |
|---|---|---|---|---|---|
| `page` | number | no | min 1 | `1` | `Page` |
| `per_page` | number | no | min 1, max 100 | `20` | `PerPage` |
| `q` | string | no | max 255 characters; case-insensitive substring of `name` (surrounding spaces ignored) | none | `Q` |

`0` or an omitted value means "use the default".

**Request example**

```ts
const params = new URLSearchParams({ page: "1", per_page: "20", q: "som" });
const res = await fetch(`${BASE_URL}/users/getData?${params}`);
const json: ApiResponse<Paginated<User>> = await res.json();
```

**Success: 200**

```json
{
  "timestamp": "2026-01-02-15-04-05",
  "status": 1,
  "items": {
    "list_data": [
      { "id": "3f1c2a9e-8b7d-4c6e-9a51-2d0f7b8e4c13", "name": "Somchai", "surename": "Phommavong" },
      { "id": "a7e4d2b1-5c3f-4e8a-b9d6-1f2e3c4d5a6b", "name": "Somsak", "surename": null }
    ],
    "pagination": { "current_page": 1, "current_page_total_item": 2, "total_page": 1 }
  },
  "error": null
}
```

No match, or a page past the end → `list_data: []`. With no matching users at all, `total_page` is `0`.

**Errors**

| HTTP | `error` message | When | UI action |
|---|---|---|---|
| 400 | `Field 'Page' \| Needs to pass 'min' validation` | `page` < 0 | reset to page 1 |
| 400 | `Field 'PerPage' \| Needs to pass 'min' validation` | `per_page` < 0 | reset page size |
| 400 | `Field 'PerPage' \| Needs to pass 'max' validation` | `per_page` > 100 | cap page-size selector at 100 |
| 400 | `Field 'Q' \| Needs to pass 'max' validation` | `q` > 255 chars | limit search input to 255 |
| 400 | Fiber bind error text | `page` / `per_page` not a number | TODO: confirm with backend (exact message) |
| 500 | database error text | unexpected server error | error state with retry |

## PUT `/api/v1/users/update/:id`

Update a user's name and, if sent, surname. Auth: none. Returns `"SUCCESS"`, **not** the updated user.

**Path params**

| Name | Type | Rule |
|---|---|---|
| `id` | string | UUID |

**Body** (`application/json`)

| Key | Type | Required | Rule | Go field (in 400 errors) |
|---|---|---|---|---|
| `name` | string | yes | max 255 characters; always overwritten | `Name` |
| `surename` | string \| null | no | max 255 characters; omitted or `null` = keep current value | `Surename` |

> A surname **cannot be cleared back to `null`** with this endpoint: `null` means "leave unchanged". Sending `""` stores an empty string.

**Request example**

```ts
const res = await fetch(`${BASE_URL}/users/update/${id}`, {
  method: "PUT",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ name: "Somchai", surename: "Vongsa" }),
});
const json: ApiResponse<"SUCCESS"> = await res.json();
```

**Success: 200**

```json
{ "timestamp": "2026-01-02-15-04-05", "status": 1, "items": "SUCCESS", "error": null }
```

**Errors**

| HTTP | `error` message | When | UI action |
|---|---|---|---|
| 400 | `Invalid uuid` | `id` is not a UUID | show "not found" |
| 400 | `Field 'Name' \| Needs to pass 'required' validation` | `name` missing or `""` | highlight `name` |
| 400 | `Field 'Name' \| Needs to pass 'max' validation` | `name` > 255 chars | highlight `name` |
| 400 | `Field 'Surename' \| Needs to pass 'max' validation` | `surename` > 255 chars | highlight `surename` |
| 400 | `Unprocessable Entity` / JSON parse message | wrong content type / malformed JSON | generic error toast |
| 500 | `user not found` | no user with that id (e.g. deleted meanwhile) | toast, go back to list and refetch |
| 500 | database error text | unexpected server error | generic error toast |

## UI hints

- **Screens:** users list page (table: name, surname; pagination with page-size selector 1–100, default 20; search box on name, `q`); user detail view; create/edit form (same fields); delete confirm dialog.
- **Form User:** `name` → text input, required, `maxLength=255`, reject empty. `surename` → text input, optional, `maxLength=255`; send `null` (or omit) when empty on create.
- **Search:** debounce the `q` input and reset `page` to 1 when it changes.
- **After success:** create → the response has the new user (navigate to its detail or prepend and refetch the list). Update → response is `"SUCCESS"`, so refetch the user/list. Delete → close the dialog and refetch the list; if the page becomes empty, go to the previous page.
- **Notes:**
  - "Not found" is **500** with `error: "user not found"`. Branch on the message.
  - Show `surename: null` as an empty cell, not the text "null".
  - Edit form: clearing the surname field can't set it back to `null` (see PUT). Decide with backend whether `""` is acceptable.
  - 400 errors name the Go field: `Name`→`name`, `Surename`→`surename`, `Page`→`page`, `PerPage`→`per_page`, `Q`→`q`.
